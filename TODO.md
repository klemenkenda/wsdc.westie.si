# Description

1. I want to create a WSDC database for Slovenian west coast swing dancers.
2. I want to have total history in there, with the events they did and results, they achieved. 
3. I want to have an entry point for each date, the results have changed.
4. I want to have personal pages of the dancers, with their history and results. As well as with their ranking withing Slovenian community.
5. I want ranking:
    A. I want to have ranking of leaders and followers separately, by primary role and by primary + secondary role.
    B. I want to have ranking absolute ranking, regardles of the role.
6. Ranking crieria is eligibility to dance in higher divisions, and points achieved in that division. If two athlethes have same points in one division, points from previous division count as a ranking criteria. If all points are the same, the ranking is the same.

# Implementation

1. Python script for accessing API is in `sample-python-wsdc-adapter.py`.
2. I want to build a PHP web application for displaying the data. I want to use Laravel framework for that. I want to have a simple design, with focus on functionality. I want to have a responsive design, so it looks good on mobile devices as well.
3. If possible, do not use the database, you can only use files, downloaded from API. But feel free to propose a MySQL database if you think it is necessary for the functionality of the application.
